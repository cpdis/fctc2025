pre-filled draft (names checked, +1s, actual kms), human confirms.

including XCUITests):** see U6.md's post-U4 notes; they apply verbatim. The
proposal seam is FROZEN and already implemented + tested:

`ChecklistViewModel.applyProposals(checks:from:)`. The manual-input-precedence
rules ("typed kms survives a dictated kms", named guests beat bare counts)
already live inside `applyProposals` with tests in `DraftProposalTests.swift` —

triage view itself is U6's deliverable: if it exists when you integrate, reuse
it; if you finish first, render your proposals with a minimal internal list and
note the swap for the orchestrator.

**Post-U5 notes (orchestrator):** `VoiceEntryParser` already delegates to U5's

## Deliverables

1. **`Services/SpeechService.swift`** (Kit) — authorization flow
   (`SFSpeechRecognizer.requestAuthorization` + mic permission), live recognition
   session with `requiresOnDeviceRecognition = true` where supported (fall back to
   server recognition only with a visible indicator), partial-results streaming,
   proper audio-session teardown. Behind `protocol Transcriber` seam for tests.
2. **`Views/VoiceEntryView`** — sheet flow from ChecklistView toolbar ("Dictate…"):
   big record button, live transcript display with subtle highlighting of tokens the
   parser is treating as names/numbers, stop → parse → same **triage list** UX as
   U6 (reuse the triage component — coordinate via the shared draft-proposal model,
   `.voice` provenance), re-record replaces the transcript. Denied-permission state
   explains and deep-links to Settings.
3. **Parsing** — `VoiceEntryParser` orchestrates `NameExtractor` (voice mode) on the
   final transcript; applies `distanceKm` to the draft's Actual kms (only if user
   hasn't already typed one — never clobber manual input) and `plusOnes` similarly;
   names → NameMatcher → triage buckets.
4. **Tests** (Kit): fake transcriber replaying fixture transcripts; full
   pipeline against `fixtures/attendance/voice-*.transcript.txt` expectations;
   manual-input-precedence rules (typed kms survives a dictated kms); ambiguous
   names require explicit pick; re-record resets proposals but not manual checks.
