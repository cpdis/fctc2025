# U8 — Hardening, integration & release

Read `_conventions.md` first. Dependencies: ALL of U2–U7 merged into
`feat/attendance-app`. This unit is part-agent, part-Colin: agents deliver everything
below except the Mac-only build/deploy steps, which use **Colin's existing TestFlight
process (in his Codex or local Claude Code tooling) — do not invent a new pipeline.**

## Objective

Close the loop: config without typing, polish, production deploy of the Apps Script,
and a real-run smoke test proving sheet fidelity end-to-end.

## Deliverables (agent-side)

1. **Config QR import** — `SettingsView` gains "Scan setup code": a QR payload
   (JSON: endpoint URL, shared secret, device name) scanned via `DataScannerViewController`
   or `AVCaptureMetadataOutput`; plus `apps-script/make-setup-qr.js` (Node, no deps —
   emits the QR as a terminal/PNG output or an HTML page Colin opens) so Aaron's
   onboarding is: install TestFlight build → scan Colin's QR → done. Secret goes to
   Keychain, never UserDefaults.
2. **Error-state polish sweep** — every SyncEngine error surfaced humanely (offline
   banner, conflict badge, bad-secret → settings prompt); empty states (no runs
   today, empty outbox); loading states on first `getState`.
3. **App icon + accent** — simple, flat, Reminders-adjacent (running-figure or track
   motif); asset catalog with all required sizes; accent color set.
4. **Release checklist** — `docs/plans/packets/U8-release-runbook.md`: numbered steps
   for Colin's Mac: `xcodegen generate` → open → sign with his team → run unit/UI
   tests → archive/upload via his existing TestFlight process; `clasp` production
   deploy steps (create deployment, set `SHARED_SECRET` + `SEASON_SHEET_NAME` script
   properties, run `apps-script/test/smoke.md` against the sheet COPY first, then
   point the app at the real deployment); secret rotation procedure; new-season
   checklist (new tab → update `SEASON_SHEET_NAME`; app self-heals via `getState`).
5. **R11 fidelity verification script** — `apps-script/test/verify-sync-fidelity.md`:
   after the first real-run submission, trigger the repo's weekly sync manually
   (`workflow_dispatch`) and diff the synced CSV row against a hand-entered control
   row: they must be indistinguishable (cell values only, `x` casing, blanks not
   zeros).

## Deliverables (Colin-side, from the runbook)

- TestFlight build on both phones; production Apps Script deployment; delete the
  smoke-test sheet copy (plan's operational note); record one real run end-to-end.

## Acceptance

- Agent-side: everything above merged, `node --test` green, runbook complete enough
  that Colin never has to guess a step.
- Overall (closes the project): both phones record a real run; next weekly sync's
  CSV diff shows exactly the expected row; dashboard renders it; no formula damage.
