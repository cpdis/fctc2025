What changed on the web

  • Header, stripe, fonts and colours match fctc.fun, so the proxy feels like one site.
  • Headline numbers compare with the same date in 2025.
  • "On a roll": current Mon/Wed/Fri streaks, the season best, and a plain rule for what a streak is.
  • The Wall: every runner × every run. Pink cells are the current streak; gold bands are specials that don't count.
  • Every run: one dot per runner, one track per club day, so the weekly rhythm and the big days are obvious.
  • Vs last year: cumulative km against 2025, with the gap at today's date labelled.
  • Milestones ahead: all-time runs close to the next 50, as gold race bibs.
  • Run log: filters move here and only apply to the table, so headline numbers never change meaning.
  • Removed: donut, spaghetti line chart, run-type small multiples, calendar heatmap, slopegraph.
